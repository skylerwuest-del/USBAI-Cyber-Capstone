# USBAI-Cyber-Capstone

The application source is in `Prototype1_demo1/`.

```bash
# First preparation (internet required for missing assets):
bash Prototype1_demo1/setup.sh
# Everyday use after setup:
bash Prototype1_demo1/launch.sh
```

The startup menu offers offline GGUF fit selection, default/manual launch, and then opens
the original application menu. Choose its option 1 to begin chat. Installed weights live in `Prototype1_demo1/models/drop-in/`.
See [application instructions](Prototype1_demo1/README.md) and
[validation results and local runtime limitations](Prototype1_demo1/VALIDATION.md).
